## Codebase Patterns
- Next.js 14 App Router project at repo root; app/ directory, tailwind.config.ts, postcss.config.js, next.config.js
- Tailwind custom colors: primary #C9A227, background #021524, surface #0e2131, on-surface #d1e5fb, outline #99907b
- TypeScript target must be ES2017+ (not ES5 — deprecated in TS 6+)
- CSS imports in layout.tsx require a css.d.ts module declaration file
- framer-motion and recharts are installed; recharts requires dynamic import with ssr: false
- Plus Jakarta Sans via next/font/google; Material Symbols via <link> in layout head
